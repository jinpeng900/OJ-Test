# 核心类接口

## DatabaseManager

| 方法 | 说明 |
| ---- | ---- |
| `DatabaseManager(host, user, password, dbname)` | 建立连接 |
| `run_sql(sql)` | 执行 SQL |
| `query(sql)` | 查询 SQL |
| `escape_string(s)` | 转义字符串 |

## User

| 方法 | 说明 |
| ---- | ---- |
| `login(account, password)` | 用户登录 |
| `register_user(account, password)` | 用户注册 |
| `change_password(old, new)` | 修改密码 |
| `submit_code(problem_id, code, language)` | 提交代码 |
| `getLastReport()` | 获取最近评测报告 |

## JudgeCore

| 方法 | 说明 |
| ---- | ---- |
| `setConfig(cfg)` | 设置评测限制 |
| `setSourceCode(code)` | 设置源码 |
| `setTestDataPath(path)` | 设置测试数据目录 |
| `judge()` | 执行评测 |

## ContainerPool

| 方法 | 说明 |
| ---- | ---- |
| `initialize()` | 初始化容器池 |
| `acquire()` | 获取容器 |
| `release(container)` | 归还容器 |
| `shutdown()` | 关闭容器池 |

## AIClient

| 方法 | 说明 |
| ---- | ---- |
| `isAvailable()` | 检查 AI 服务可用性 |
| `ask(message, codeContext, problemContext)` | 调用 AI |

## ViewManager

| 方法 | 说明 |
| ---- | ---- |
| `render()` | 每帧绘制当前页面 |
