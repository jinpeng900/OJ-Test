# 数据库表结构

## 数据库

默认数据库：

```text
oj_system
```

## users

保存普通用户和管理员登录信息。

| 字段 | 说明 |
| ---- | ---- |
| `id` | 用户 ID |
| `account` | 账号 |
| `password_hash` | SHA256 密码哈希 |
| `role` | 用户角色 |
| `submission_count` | 提交次数 |
| `solved_count` | 通过题目数 |
| `last_login` | 最后登录时间 |
| `created_at` | 创建时间 |

## problems

保存题目信息。

| 字段 | 说明 |
| ---- | ---- |
| `id` | 题目 ID |
| `title` | 标题 |
| `description` | 题面 |
| `category` | 知识点 |
| `time_limit` | 时间限制 |
| `memory_limit` | 内存限制 |
| `test_data_path` | 测试数据目录 |
| `created_at` | 创建时间 |

## submissions

保存提交记录。

| 字段 | 说明 |
| ---- | ---- |
| `id` | 提交 ID |
| `user_id` | 用户 ID |
| `problem_id` | 题目 ID |
| `code` | 提交代码 |
| `language` | 语言 |
| `status` | 评测状态 |
| `submit_time` | 提交时间 |

## 状态枚举

| 状态 | 含义 |
| ---- | ---- |
| `AC` | Accepted |
| `WA` | Wrong Answer |
| `TLE` | Time Limit Exceeded |
| `MLE` | Memory Limit Exceeded |
| `RE` | Runtime Error |
| `CE` | Compile Error |
| `SE` | System Error |
