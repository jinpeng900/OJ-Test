# 数据库访问与权限

## DatabaseManager

`DatabaseManager` 封装 MySQL C API。

主要接口：

| 接口 | 功能 |
| ---- | ---- |
| `run_sql()` | 执行无返回 SQL |
| `query()` | 查询并返回 `vector<map<string,string>>` |
| `escape_string()` | 转义用户输入 |

## 数据库用户

`init.sql` 初始化两个数据库账号：

| 账号 | 用途 |
| ---- | ---- |
| `oj_admin` | 管理员数据库操作 |
| `oj_user` | 普通用户数据库操作 |

同时为 `localhost` 和 `%` 创建授权，兼容本地运行和 Docker Compose 网络。

## 连接地址

代码通过环境变量读取数据库地址：

```text
OJ_DB_HOST
```

默认值为：

```text
127.0.0.1
```

Docker Compose 中 `oj-app` 与 `oj-db` 共享网络命名空间，因此应用连接 `127.0.0.1` 即可访问数据库容器。

## 安全现状

已做：

- 登录、注册、提交代码等关键输入使用 `escape_string()`。
- 密码使用 SHA256 哈希保存。
- 普通用户和管理员数据库账号分离。

待优化：

- 全面切换 prepared statement。
- 增加数据库迁移版本管理。
- 保存更完整的提交评测详情。
