# 管理员业务模块

## 主要职责

管理员模块包含两层：

- `AdminView`：管理员 GUI 页面。
- `Admin`：管理员业务逻辑和数据库操作。

## 登录

管理员账号由 `init.sql` 初始化。默认图形界面管理员为：

| 账号 | 密码 |
| ---- | ---- |
| `admin` | `admin123` |

## 添加题目

v2.0 管理员添加题目使用 GUI 表单，字段包括：

- 标题
- 知识点
- 时间限制
- 内存限制
- 测试数据路径
- 题目描述

测试数据路径示例：

```text
data/9
```

目录中应包含：

```text
1.in
1.out
2.in
2.out
...
```

## 当前限制

- 只能添加题目，暂不支持编辑和删除题目。
- 不支持在 GUI 中上传测试数据。
- 管理员操作没有审计日志。
