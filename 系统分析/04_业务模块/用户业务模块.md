# 用户业务模块

## 主要职责

`User` 封装普通用户相关业务：

- 登录
- 注册
- 修改密码
- 查看题目
- 提交代码
- 查看提交记录
- 保存工作区文件
- 缓存最近评测报告

## 登录注册

用户密码使用 SHA256 哈希存储。账号输入经过 `DatabaseManager::escape_string()` 转义后再拼入 SQL。

登录成功后会：

- 设置当前用户 ID
- 设置当前账号
- 更新最后登录时间
- 创建用户独立工作区

## 代码提交

`submit_code()` 的职责包括：

- 查询题目配置
- 设置 `JudgeConfig`
- 将代码传入 `JudgeCore`
- 执行评测
- 将最终状态和代码写入 `submissions`
- 更新用户提交数
- 首次 AC 时更新用户通过数
- 保存 `last_report`

## 工作区

v2.0 使用用户独立工作区：

```text
workspace/<user_id>/solution.cpp
```

这样不同用户不会互相覆盖代码。

## 当前限制

- 提交后 GUI 会同步等待评测结束。
- `submissions` 当前保存最终状态和提交代码，未保存完整逐测试点详情。
- SQL 还没有全面改为 prepared statement。
