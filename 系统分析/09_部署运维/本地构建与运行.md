# 本地构建与运行

## 依赖

本地运行需要：

- CMake
- g++ with C++17
- MySQL client dev library
- OpenSSL
- GLFW3
- OpenGL
- Docker
- Python3

## 构建

```bash
mkdir -p build
cd build
cmake ..
cmake --build . -j
./oj_app
```

## 数据库

本地运行时需要 MySQL 已启动，并执行过 `init.sql`。

应用默认连接：

```text
127.0.0.1
```

也可以通过环境变量指定：

```bash
export OJ_DB_HOST=127.0.0.1
```

## 评测

本地运行时仍需要 Docker，因为评测沙箱依赖 Docker 容器。

如果没有 `judge-sandbox:latest`，需要先构建：

```bash
docker build -t judge-sandbox:latest judge-sandbox
```
