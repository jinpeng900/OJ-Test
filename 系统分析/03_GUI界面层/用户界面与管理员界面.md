# 用户界面与管理员界面

## UserView

`UserView` 负责普通用户界面。

| 页面 | 方法 | 功能 |
| ---- | ---- | ---- |
| 登录 | `draw_login()` | 用户登录 |
| 注册 | `draw_register()` | 新用户注册 |
| 菜单 | `draw_menu()` | 进入题目、提交、AI、改密 |
| 题目列表 | `draw_problem_list()` | 搜索、查看题目、显示完成标记 |
| 题目详情 | `draw_problem_detail()` | 题面、代码编辑、保存、提交 |
| 评测结果 | `draw_submit_result()` | 显示 `JudgeReport` |
| 提交列表 | `draw_submissions_list()` | 展示历史提交 |
| 提交详情 | `draw_submission_detail()` | 展示状态原因和提交代码 |
| 改密 | `draw_change_password()` | 修改密码 |
| AI | `draw_ai_assistant()` | AI 问答 |

## AdminView

`AdminView` 负责管理员界面。

| 页面 | 功能 |
| ---- | ---- |
| 管理员登录 | 验证管理员账号 |
| 管理员菜单 | 查看题目、添加题目 |
| 添加题目 | 表单录入题目字段 |

## v2.0 重点改动

- 管理员添加题目从“手写 SQL”改为表单。
- 用户提交列表支持点击进入详情。
- 已完成题目标记从绿色问号改成 ImGui 绘制绿色方块。
- 题目详情页支持直接编辑多行代码。
