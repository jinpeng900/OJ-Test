# 当前限制与后续规划

## 当前限制

| 限制 | 说明 |
| ---- | ---- |
| 桌面 GUI | 当前不是 Web 服务，远程访问不方便 |
| X11 依赖 | Docker 运行 GUI 依赖图形显示 |
| 同步评测 | 提交时界面会等待 |
| 单语言 | 当前主要支持 C++17 |
| 提交详情不足 | 未保存完整逐测试点 diff 和编译错误全文 |
| Docker Socket | 主程序可控制宿主机 Docker |
| SQL 安全 | 尚未全面使用 prepared statement |
| 管理员能力 | 只能添加题目，不能编辑、删除、上传测试数据 |

## v2.1 计划

- 异步评测
- 提交详情保存完整评测报告
- 管理员编辑和删除题目
- 测试数据管理
- 全面 prepared statement
- 更完整的错误弹窗和状态提示

## v2.2 计划

- 多语言评测
- 排行榜
- 题目难度和多标签
- 提交筛选
- AI 基于提交记录做错误分析

## 长期规划

- Web 前端
- 服务端 API
- 分布式评测 worker
- 比赛模式
- 操作审计
- 更严格的沙箱安全策略
