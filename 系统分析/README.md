# OJ 系统分析文档

本目录依据 `.qoder/repowiki` 中的知识库结构，并结合当前 v2.0 代码与 `README.md` 重新整理。

`.qoder` 中大量内容仍停留在 v1.x 的命令行交互阶段，因此这里不直接复制原文，而是按 v2.0 的实际状态重写为正式系统分析文档。

## 当前版本基准

- 系统版本：v2.0
- 交互方式：ImGui 桌面 GUI
- 部署方式：Docker Compose 优先，本地构建可选
- 数据库：MySQL
- 评测方式：Docker 沙箱容器
- AI 服务：DeepSeek API + Python LangChain
