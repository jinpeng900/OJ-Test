# 技术栈与目录结构

## 技术栈

| 技术 | 用途 |
| ---- | ---- |
| C++17 | 主程序、业务逻辑、评测调度 |
| Dear ImGui | 桌面 GUI |
| GLFW / OpenGL | 窗口与图形渲染 |
| MySQL C API | 数据库连接和查询 |
| OpenSSL EVP | 密码 SHA256 哈希 |
| Docker CLI | 创建和控制评测沙箱 |
| Docker Compose | 启动数据库和主程序容器 |
| Python / LangChain | AI 服务封装 |
| DeepSeek API | AI 问答和辅助调试 |
| CMake | 本地构建系统 |

## 目录结构

| 路径 | 说明 |
| ---- | ---- |
| `src/` | C++ 实现文件 |
| `include/` | C++ 头文件 |
| `data/` | 题目测试数据 |
| `ai/` | AI Python 服务与依赖 |
| `judge-sandbox/` | 评测沙箱镜像 |
| `deps/imgui/` | ImGui 源码依赖 |
| `docs/` | 设计文档 |
| `History/` | 版本演进记录 |
| `系统分析/` | 当前系统分析文档 |
| `workspace/` | 运行时用户代码工作区，不进入版本库 |
| `build/` | 本地构建产物，不进入版本库 |

## 可提交与不可提交内容

应提交：

- 源码、头文件、测试数据、Docker 配置、README、历史文档、系统分析文档

不应提交：

- `build/`
- `workspace/`
- `ai/.env`
- IDE 配置
- `.qoder/`
- 本地运行缓存
