# 系统介绍

## 定位

本项目是一个基于 C++17 实现的桌面版 OJ 在线判题系统。v2.0 的核心变化是从 v1.x 的终端菜单程序升级为 ImGui 图形界面程序。

系统面向编程训练、课程实验和 C++ 工程化学习，重点展示以下能力：

- 用户注册、登录、改密
- 题目浏览、搜索、详情查看
- GUI 内编辑代码并提交评测
- Docker 沙箱编译运行用户代码
- MySQL 持久化用户、题目、提交记录和提交代码
- 管理员图形化添加题目
- AI 辅助调试和题目推荐

## 角色

| 角色 | 能力 |
| ---- | ---- |
| 普通用户 | 登录注册、浏览题目、编辑代码、提交评测、查看提交详情、使用 AI |
| 管理员 | 登录后台、查看题目、添加题目 |
| 系统维护者 | 配置 Docker、数据库、AI 环境和测试数据 |

## v2.0 关键特征

- 使用 GLFW + OpenGL + Dear ImGui 构建桌面窗口。
- 通过 `GUIState` 管理页面状态。
- 每个用户有独立 `workspace/<user_id>/solution.cpp`。
- 已完成题目使用绿色方块标记，避免字体缺字导致问号。
- 提交详情页展示状态、原因说明和提交代码。
- Docker Compose 负责启动数据库和 GUI 主程序。
- `oj-app` 通过宿主机 Docker Socket 创建评测沙箱。
